# paper/figures — ACII 2026 figure registry

Shared style: **`_style.py`** (P1). Canonical data + numbers: **`../data_inventory.md`** (P0).

Every figure script is run from **inside this directory** and begins:

```python
from _style import (setup_ieee, save_fig, set_size, seed_all,
                     ONE_COL, TWO_COL, PALETTE_QUAL, PALETTE_SEQ, PALETTE_DIV)
setup_ieee()
seed_all(42)
```

Outputs: `{name}.pdf` (vector, submission) + `{name}.png` (300 dpi, preview).
IEEE geometry: `ONE_COL=3.45in`, `TWO_COL=7.16in`. Fonts embedded (`pdf.fonttype=42`).
